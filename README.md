# PK Navigator Recruiter Build

This folder contains a recruiter-facing packaged desktop build of PK Navigator for macOS.

## Contents

- `PK Navigator-0.1.0-arm64.dmg`: installable Apple Silicon Mac build

## How to use

1. Open the DMG.
2. Drag `PK Navigator` into `Applications`.
3. Launch the app from `Applications`.

## Notes

- This package is intended for review and demonstration.
- It does not expose the source tree.
- The source repository is maintained separately.

## Platform

- macOS Apple Silicon (`arm64`)

If you need an Intel Mac build or a Windows installer, package those on the matching platform.
